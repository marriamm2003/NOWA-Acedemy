# NOWA Culinary Academy

Modular culinary courses, chef profiles, learning paths, and a curated chef's market.

Built with TanStack Start (React 19, Vite, Tailwind CSS v4). Arabic-first with full RTL support and English toggle.

## Development

```sh
npm install --legacy-peer-deps --force
npm run dev
```

## Build

```sh
npm run build
```
